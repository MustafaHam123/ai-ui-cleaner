# Installation

The maintained instructions for all four hosts are in the [README installation section](../README.md#install):

- [Codex desktop](../README.md#codex-desktop-app)
- [Codex terminal](../README.md#codex-terminal)
- [Claude Code desktop](../README.md#claude-code-desktop-app)
- [Claude Code terminal](../README.md#claude-code-terminal)

Install the plugin to get both the skill and hosted MCP configuration. An MCP URL by itself does not download the skill. GitHub holds the package; Cloudflare holds the corpus. Updated local files must be pushed before others can download them, and existing users must update their installed copy.
