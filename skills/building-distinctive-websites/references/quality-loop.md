# Quality loop

Use up to three passes. Each pass should identify and repair a small number of high-impact problems rather than restyling everything.

## Pass 1: Structure

Check content order, primary task, hierarchy, scan path, density, and responsive priority. Fix structural problems before polish.

## Pass 2: System

Check typography, spacing rhythm, color roles, surfaces, component consistency, focus states, and contrast. Consolidate arbitrary values into project tokens when appropriate.

## Pass 3: Character and finish

Check whether the result has a coherent point of view without borrowing a source's identity. Review media treatment, empty and error states, motion purpose, overflow, and small-screen details.

When screenshots or a browser are available, inspect at minimum:

- A wide desktop viewport.
- A narrow mobile viewport.
- One intermediate width where grids and navigation often break.
- Long content, empty content, and a failure state when the product supports them.

Stop when remaining changes are cosmetic, speculative, or outside the request. Do not loop indefinitely.
